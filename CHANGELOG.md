## [1.0.0] - 2026-02-21

### Added
- Initial release
- 14 domain tools + 3 premium tools + 2 meta tools (19 total)
- SBOM standards: SPDX 2.3/3.0 and CycloneDX 1.5/1.6 field specifications
- SLSA framework levels 1-4 with evidence and verification criteria
- Supply chain regulations: EU CRA, US EO 14028, NIST SSDF
- Supply chain attack patterns with MITRE ATT&CK and CAPEC mapping
- Signing and attestation patterns: Sigstore, in-toto, Notary v2
- Composition risk assessment: dependency confusion, typosquatting, maintainer compromise
- Premium version tracking tools (gated by PREMIUM_ENABLED)
- SQLite + FTS5 full-text search across all data tables
